I am a Senior Frontend Engineer with almost 8 years of experience building and modernizing enterprise applications across fintech, banking, healthcare, industrial IoT, e-commerce and weather intelligence.

Engineering principles

01. Prefer clear architecture over accidental complexity.
02. Build reusable components without creating unnecessary abstractions.
03. Keep state predictable and close to where it is consumed.
04. Treat performance, accessibility and testing as engineering concerns.
05. Modernize legacy systems incrementally and safely.
06. Optimize for maintainability and long-term product evolution.
07. Use AI-assisted tools to accelerate work without reducing code quality.
